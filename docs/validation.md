# 验证指南

公开版本不包含个人课程、登录记录、课表、课件或真实账号验收数据。测试使用临时目录、合成媒体和模拟平台响应。

```sh
python -m unittest discover -s tests -v
cd webui
npm ci
npm test
npm run build
```

测试范围包括鉴权状态、平台错误分类、执行队列与恢复、媒体处理、二维码、Web API、访问密码、Codex 会话包装与前端数据组织。Codex 自动化测试使用本地假 CLI，不调用真实模型或发送作业。

需要真实账号、学校平台或模型的手工验证应在自己的私有运行目录内完成。未在所有操作系统或长期无人值守场景下验证，不保证外部平台接口长期不变。
